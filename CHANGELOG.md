# Changelog

## 0.4.0-beta.1

Initial Hyper AI Lab public beta, derived from the upstream MIT implementation.

- Bounded stdio MCP evidence discovery, Jev selection and hash-verified exact reads.
- Query-prioritized local discovery, typed ranges, previews and recoverable omissions.
- Shared privacy, authorization, cache, spending and quota controls across entrypoints.
- Conservative crash-reservation reconciliation and owner-acknowledged Git recovery.
- Model-neutral, ownership-aware installation, upgrade, rollback and uninstall.
- Explicit paid opt-in; default activation preserves configured request caps.
- Metadata-only measurement coverage and an honest incomplete-comparison report.
- Offline fault-injection, package lifecycle and synthetic retrieval test suites.
- Clean public history, upstream attribution, security reporting and CI.

Generalized native-token/cost/speed improvements and Mac-local execution are not
established. This beta is not a certified universal context-optimization layer.
